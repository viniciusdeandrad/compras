Como funciona: O sistema cruza VENDAS (consumo) × ENGENHARIA (quanto de cada insumo cada produto consome) × ESTOQUE (o que você tem) × PEDIDOS (o que já comprou) e te diz exatamente quanto e quando comprar. A lógica: se faltam menos de 60 dias de cobertura, é sinal de compra.
Sobre essências: Este sistema é focado em insumos físicos (tampas, válvulas, frascos, cartonagens, rótulos, selos, sleeves). Itens com categoria "ESSÊNCIA" são ignorados automaticamente — eles são controlados no sistema PCP.
Engenharias: O arquivo SUPLY_-_GERAL contém múltiplas abas (BODY SPLASH, SUPPLY - 50ML, SUPPLY - SPECIAL, MEMÓRIAS, CORPO, SUPPLY - 30ML). Cada aba traz, para cada produto, os SKUs de TAMPA, VÁLVULA, FRASCO, CARTONAGEM, RÓTULO, SELO, ESSÊNCIA e a quantidade por unidade.

☁️ Backup & Git (dados compartilhados)

Os dados ficam salvos neste navegador. Para compartilhar com outra pessoa e ter backup versionado, use um arquivo backup.json no repositório:

  1. Clique em Salvar backup pro Git abaixo — baixa o arquivo backup.json.
  2. Coloque-o na pasta do repositório (substituindo o anterior) e faça commit + push.
  3. Quando alguém abrir o sistema, ele carrega automaticamente o último backup.json commitado.

⚠️ Não é tempo real: se duas pessoas editam ao mesmo tempo, vale combinar quem salva (puxar do git → editar → exportar → commitar). A auto-carga só roda quando o sistema está hospedado (ex.: GitHub Pages); abrindo o arquivo direto do disco o navegador bloqueia a leitura.

Kits compartilhados

Insumos comuns que aparecem em toda uma linha de produtos (ex: TAMPA 50ML que é igual para todos os VIPs, ou VIDRO YES que é igual para todas as Memórias YES). Em vez de cadastrar manualmente em cada engenharia, basta declarar um kit e o sistema soma o consumo automaticamente para todos os produtos da linha.

Como funciona: O sistema detecta a linha pelo nome do produto (VIP, FIT, LUX, SPA, DESODORANTE COLONIA YES, etc) e aplica o kit correspondente. Insumos já cadastrados na engenharia explícita do produto têm prioridade — o kit só adiciona o que falta. Se quiser desabilitar o kit para um produto específico, use a aba "Overrides".

Veja qual kit foi detectado para cada produto e o que será somado na demanda. Clique em "↺" para limpar override manual e voltar à detecção automática.
